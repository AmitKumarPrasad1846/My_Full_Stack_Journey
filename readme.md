## 🌟 Overview

Welcome to **My Full-Stack Journey** — a structured, project-driven curriculum covering everything from the very first HTML tag to DOM manipulation in JavaScript, design workflows in Figma, and an introduction to Java for backend development.

This isn't just a course archive — it's a real learning journey, documented step-by-step across **69+ video tutorials**, **11+ exercises with solutions**, and **real-world projects** like a Netflix clone.

> *"The best way to learn web development is to build things. This repository is proof of that."*

### 🎯 What's Inside

| Area | Topics Covered |
|------|---------------|
| 🏗️ **HTML** | Semantic structure, accessibility, multimedia, best practices |
| 🎨 **CSS** | Flexbox, Grid, animations, responsive design, components |
| ⚡ **JavaScript** | DOM manipulation, ES6+, functions, loops, arrays |
| 🖌️ **Design** | Figma design-to-code workflow, UI principles |
| ☕ **Java** | Introduction to backend programming concepts |

## 🚀 Getting Started

### Prerequisites

- A code editor — **[VS Code](https://code.visualstudio.com/)** recommended
- A modern browser (Chrome, Firefox, Edge)
- Git installed
- [VS Code Live Server extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) for hot reload

### Setup

```bash
# 1. Clone the repository
git clone https://github.com/AmitKumarPrasad1846/My_Full_Stack_Journey.git

# 2. Navigate into the project
cd My_Full_Stack_Journey

# 3. Open any lesson folder
cd "video 1"

# 4. Open in VS Code
code .
# Then right-click index.html → Open with Live Server
```

### Folder Structure

```
My_Full_Stack_Journey/
│
├── video 1–11/              # 📄 HTML Fundamentals
│   └── index.html / guide.html / assets/
│
├── video 12–51/             # 🎨 CSS & Layout
│   ├── video 12 exercise 1/
│   ├── video 16 solution/
│   └── ... (8 exercises + solutions)
│
├── video 52–53/             # 🚀 Special Projects
│   ├── video 52 Figma/
│   └── video 53 Netflix Clone/
│
└── video 54–69+/            # ⚡ JavaScript & Java
    ├── video 59 exercise 9/

```

## 💡 How to Use This Repo

**Complete Beginner?**
Start at Video 1, go sequentially. Don't skip exercises — they're placed right where the concepts click.

**Have Some Experience?**
Skim Phase 1, deep-dive Phase 2 onwards. Focus on exercises before checking solutions.

**Building a Portfolio?**
Complete the Netflix Clone (Video 53), customize it, and deploy it to [GitHub Pages](https://pages.github.com/) or [Netlify](https://www.netlify.com/).

**Just Practicing?**
Jump into any exercise, attempt it without looking at the solution, then compare.
